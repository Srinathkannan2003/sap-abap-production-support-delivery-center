# Incident Management Guide

1. Capture incident category, module, priority, user impact, and timestamp.
2. Assign the right consultant based on module ownership and capacity.
3. Review SLA and escalation risk.
4. Perform RCA using ST22, SM37, SMQ1/SMQ2, WE02, SLG1, or application logs.
5. Apply fix through governed ABAP change and peer review.
6. Validate in QA/UAT and update closure notes with cause, fix, and prevention.
